# Daily Engineering Checklist

Use this checklist every single day without exception. Copy or check off these items daily to maintain ruthless consistency.

---

### 🌅 Morning Routine (06:00 – 09:00)
- [ ] Review Today's Mission & README
- [ ] Study Theory & Real-World Company Use Cases
- [ ] Hand-draw Memory & Architecture Diagrams on Paper
- [ ] Complete Foundation Examples (write from scratch, don't copy-paste)
- [ ] Solve Core Exercises (verify output in terminal)

---

### 💻 Afternoon Routine (09:00 – 14:00)
- [ ] Solve 5–10 Coding Assignment Problems (increasing difficulty)
- [ ] Build & Run Today's Mini Project
- [ ] Review AI-Generated Code (critique, optimize, identify pitfalls)
- [ ] Answer & Practice Interview Questions (say answers out loud)
- [ ] Send 20–30 Job Applications (LinkedIn / Wellfound / Naukri)
- [ ] Send 5–10 Personalized Recruiter / Engineering Lead Connection Requests

---

### 🚀 Evening Routine (14:00 – 21:00)
- [ ] Send 10 Freelancing Proposals (Upwork / Freelancer / Direct outreach)
- [ ] Build / Ship 1 Feature or Fix on **OneBridge Social**
- [ ] Review Day's Checklist & Log Daily Reflection (`Reflection.md`)
- [ ] Stage, Commit & Push Today's Code to GitHub:
  ```bash
  git add .
  git commit -m "Day XX: <Summary of accomplishments>"
  git push origin main
  ```
- [ ] Post Daily Proof-of-Work to Instagram (**@codvinu.ai**) with Carousel, Caption & Notes.
