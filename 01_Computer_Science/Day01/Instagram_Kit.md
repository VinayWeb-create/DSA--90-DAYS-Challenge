### Slide 2: The Hardware Journey (From SSD to CPU)
* **Bullet 1:** **SSD/HDD (Storage):** Where your `.py` or `.js` file lives permanently.
* **Bullet 2:** **RAM (Memory):** When you run a program, the OS copies it into RAM. CPU never runs directly from disk!
* **Bullet 3:** **CPU (The Brain):** Executes instructions at billions of cycles per second using the Fetch-Decode-Execute loop.
* **Key Takeaway:** Speed difference is 100,000x between RAM and SSD!

---

### Slide 3: Process vs. Thread (The Office Analogy)
* **Process = Office Building:**
  - Independent memory space.
  - If Chrome crashes, VS Code keeps running.
* **Thread = Employees inside the office:**
  - Lightweight workers sharing the same Heap.
  - One thread handles downloads, one renders UI.
* **Key Difference:** Processes are isolated; threads share memory!

---

### Slide 4: Stack vs. Heap (Plates vs. Warehouse)
* **Stack Memory:**
  - LIFO (Last-In-First-Out).
  - Holds function calls & local variables.
  - Fast, auto-cleaned when function exits.
  - Overflow = `RecursionError` / Stack Overflow.
* **Heap Memory:**
  - Dynamic warehouse.
  - Holds objects, lists, dictionaries.
  - Managed by Garbage Collection.
  - Leak = Out of Memory (OOM).
