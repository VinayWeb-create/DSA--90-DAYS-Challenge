# Day 01: Curated Learning Resources

Expand your understanding with these industry-standard resources:

---

## 📖 Recommended Books & Papers
1. **Operating Systems: Three Easy Pieces (OSTEP)** — Remzi Arpaci-Dusseau (Free online: Chapters on Virtualization, Processes, and Memory).
2. **Computer Systems: A Programmer's Perspective (CS:APP)** — Randal E. Bryant & David R. O'Hallaron (Chapters 1 & 9).
3. **Fluent Python (2nd Edition)** — Luciano Ramalho (Chapter on Python Data Model and Object References).

---

## 🎥 Video Lectures & Interactive Explorers
1. **Crash Course Computer Science:**
   - Episode 5: How a CPU Works
   - Episode 7: Memory & Storage
   - Episode 31: Operating Systems & Virtual Memory
2. **Python Tutor (pythontutor.com):**
   - Paste any Python snippet to visualize the Call Stack and Heap objects step-by-step in real time!
3. **Ben Eater's 8-bit Computer from Scratch (YouTube):**
   - The best visual representation of how registers, buses, and RAM actually wire together.
