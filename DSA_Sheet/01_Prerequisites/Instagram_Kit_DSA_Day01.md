### Slide 4: Mistakes I Made & Lessons Learned 💡
* **Bug #1:** Used `return` instead of `break` inside a loop
  - `return` exits the **entire function** 🚪
  - `break` exits only the **loop** 🔄
* **Bug #2:** Counted duplicates instead of distinct elements
  - Wrong approach: Look **forward** for matches
  - Right approach: Look **backward** + use a flag
* **Bug #3:** Used `print()` inside function instead of `return`
  - Function returned `None` alongside printed output
* **Takeaway:** Debugging is where the real learning happens! 🧠
