# DSA--90-DAYS-Challenge

A structured 90-Day Data Structures & Algorithms (DSA) and Computer Science journey in Python — covering fundamentals, algorithms, time complexity optimizations, and interview preparation.

## 📌 Repository Overview

- **`00_Roadmap/`**: 90-Day Master Roadmap, Daily Checklists, and Weekly Reviews.
- **`01_Computer_Science/`**: Core CS concepts (Execution model, memory, processes vs threads, stack vs heap, CLI mini-projects).
- **`DSA_Sheet/`**: 
  - `01_Prerequisites/`: 33 foundational number theory and math algorithms (Primes, Fibonacci, Armstrong, Automorphic, Harshad, Abundant, Friendly Pairs).
  - Social & Visual kits with Big-O breakdowns and algorithm cheat sheets.
